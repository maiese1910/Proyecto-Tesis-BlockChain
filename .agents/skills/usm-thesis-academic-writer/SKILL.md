# USM Systems Engineering Thesis Writer Skill

## Strict Academic Rules
1. **Impersonal Third Person Only:** Redact all paragraphs strictly in the third person singular (e.g., *"Se observa que"*, *"El prototipo procesa"*, *"La investigación establece"*). Never use first person (*"Desarrollé"*, *"Nuestro proyecto"*).
2. **USM 2023 Manual Compliance:**
   - Research questions and specific objectives must align 1-to-1 and begin with infinitive verbs (*Diagnosticar, Determinar, Diseñar, Construir, Evaluar*).
   - Maintain neutral, unbiased phrasing in all data collection and validation instruments.
3. **Legal & Repository Grounding:**
   - Always cite exact laws and articles from `.agents/skills/usm-thesis-academic-writer/references/marco-legal-venezuela.md` in descending hierarchical order (Kelsen pyramid).
   - Consult `.agents/skills/usm-thesis-academic-writer/references/usm-format-and-project-docs.md` so technical architecture descriptions accurately reflect the real stack (Flask, React 19 + Vite, OpenCV + Gemini Vision, Supabase, IPFS, Solidity Sepolia).
